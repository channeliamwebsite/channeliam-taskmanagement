## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Local database

`npm run dev` uses whatever Supabase project `.env.local` (or `.env.development.local`) points at. To develop against the local Supabase stack instead, which has every migration in `supabase/migrations`, run:

```bash
npx supabase start
npm run dev:local
```

`dev:local` reads the local stack's URL and keys from `supabase status`, sets them for that process only (they override the `.env` files), and refuses to start if the local stack isn't running. Sign in with the test accounts listed in `supabase/seed.sql`.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.
